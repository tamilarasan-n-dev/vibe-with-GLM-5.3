# Tooling Taste

- Prefers Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui for React projects, deployed on Vercel with automatic CI/CD. Confidence: 0.9
- Prefers Framer Motion for UI-level animations (hover, stagger, page transitions) and GSAP for cinematic sequences (hero text reveals, scroll-triggered timelines, parallax, split text), plus Lenis for smooth scrolling. Confidence: 0.9
- Uses React Three Fiber / Three.js only where it meaningfully enhances the experience (hero/background effects), not gratuitously. Confidence: 0.8
- Prefers Lucide React for icons, MDX for blog content, next-themes for theming, React Hook Form + Zod for form validation, Resend + Server Actions for contact forms, and lightweight analytics (Plausible / Vercel Analytics). Confidence: 0.7
